# Оно тебе надо

Проектная работа первого спринта Яндекс Практикума.

## Структура

- `index.html` — разметка страницы;
- `styles/global.css` — глобальные стили и сбросы;
- `styles/style.css` — стили блоков страницы;
- `fonts/` — локальные шрифты Raleway;
- `images/` — изображения и SVG-иконки.

## Запуск

Откройте `index.html` в браузере или запустите проект через расширение Live Server.
